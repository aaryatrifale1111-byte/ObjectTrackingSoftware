
# YOLO + SAM2 Object Detection and Tracking

Standalone Windows desktop application for live industrial camera acquisition, object detection and tracking.

## Planned Features

- GenTL camera acquisition
- OpenCV frame conversion
- YOLO object detection
- SAM2 segmentation and tracking
- Persistent object IDs
- Automatic exposure
- Autofocus
- Live video display
- Video and tracking data recording

## Development Environment

- Python
- PySide6
- OpenCV
- Harvester / GenTL
- PyTorch
- Ultralytics YOLO
- SAM2

## Target Platform

Windows 10 / Windows 11 (64-bit).
